# Questie Panza

A vibecoded addon for World of Warcraft Forever that disables the annoying quest announce messages from your party members sent by Questie.

## Installation

1. Download the ZIP or clone the repository.
2. Put the `Questie_Panza` folder into your `Interface\AddOns\` directory.
3. Enable it in-game and you're good to go.

## Files

- `Questie_Panza.toc`
- `Questie_Panza.lua`
